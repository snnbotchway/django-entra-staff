# Agent instructions

`django-entra-staff`: a public Django package, built on django-allauth, for staff sign-in with Microsoft Entra and passwords. Read `GLOSSARY.md` and `docs/adr/` first. Keep it general: no organisation names, wording or groups in the code; those come from each App's settings.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
