# Refuse Password sign-in once a User has a Microsoft link

When a User gets a Microsoft link, its password is removed and Password sign-in is refused from then on. Passwords exist only for people with no work Microsoft account and for local development users, which never get a link. The reason is leavers: IT disables a leaver in Entra, which ends Microsoft sign-in everywhere at once, but a password would keep opening every App until someone blocked the User in each one. This also means every Microsoft person gets Entra's own MFA and Conditional Access on every sign-in. We rejected keeping both methods (leavers must be blocked by hand in each App) and checking Microsoft Graph for disabled people (more code and more Entra permissions). Password reset is therefore offered only to Users that already have a password, so it can never add one to a linked User.
